# On This Day
On This Day is a Chrome extension that displays past historical events on the current day. It works every day of the week, and gets its information via Wikipedia.

# Download
Once you have the repo on your device, go to <a href="chrome://extensions/">chrome://extensions/<a>. 

Once there, toggle on *developer mode*. Click "Load unpacked" and then select the onthisday folder.

Once you have these steps done, make sure you pin the extension to your toolbar!
